# Course-Recommendations-System
This project implements an intelligent course recommendation system designed to help students make informed decisions about course selection. Unlike traditional rule-based systems, this MVP leverages classical machine learning models to predict:
- Success Probability - Likelihood of passing a course (Logistic Regression)
- Expected Grade - Predicted final grade on a 0-10 CGPA scale (Linear Regression)
The system analyzes student academic profiles, course difficulty levels, and historical enrollment data to generate personalized recommendations.

Features offered by this project:   
- For Students

  Personalized Recommendations: Top course suggestions based on individual academic profile
  Success Prediction: Know your probability of passing before enrollment
  Grade Forecasting: Expected grade prediction (0-10 scale)
  Visual Analytics: Interactive charts showing predicted performance
- For Educators

  Data-Driven Insights: Understand student-course compatibility patterns
  Performance Metrics: Model accuracy, precision, and RMSE tracking
  Difficulty Analysis: Course difficulty impact visualization
